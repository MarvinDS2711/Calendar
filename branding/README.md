# Logo INOVACOM

Déposez ici le logo officiel, sous l'un de ces noms (le premier trouvé est utilisé) :

- `logo.svg`
- `logo.png` ← recommandé : PNG carré à fond transparent, 512 × 512 px minimum
- `logo.webp`, `logo.jpg`

Il est pris en compte immédiatement, sans recompilation ni redémarrage : en-tête, favicon,
écran de connexion et **animation de confirmation** (révélation du logo dans le sens
d'un tracé de coche, reflet lumineux, anneaux). Il suffit d'actualiser la page.
